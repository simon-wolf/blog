Org is an Emacs major mode which is designed for note-taking and task management but it is also an authoring and publishing system, including support for working with source code. These notes are both my personal aid to remembering things whilst I become familiar with it but they may also be helpful for others who are new to Emacs and Org and want to dig into it.


| Key Sequence | Action |
| --- | --- |
| TAB | Fold/Unfold heading (use on the heading line itself) |
| S-TAB | Fold/Unfold everything (level 1 headings only -> all headings -> everything) |
| M-RET | New heading at the same level as the previous one |
| C-RET | New heading after the current subtree  |
| M-left/right | Change heading level |
| M-up/down | Move heading and subtree |
| C-x n s | Narrow to subtree |
| C-x n w | Widen back to full document |

| C-c @ | Mark subtree |

## Document Structure

Headings are not just visual. They are containers which can have properties, metadata and behaviours.

## Text Formatting

Just like Markdown, Org-Mode supports text formatting:

```
*bold text*
/italic text/
_underlined text_
=verbatim text= (monospace)
~code~ (monospace)
+strikethrough text+
```

## Escaping Special Characters

See the [Org-Mode manual](https://orgmode.org/manual/Escape-Character.html) for full details. 

### General Cases

In general cases, you precede special characters with a zero width space:

`C-x 8 `

(Ctrl-x, then 8, then a space)

Emacs will show a highlighted underscore and then you can type the special character.

### Literal Examples

Literal examples are typeset in monospace and they are like code blocks in Markdown:

```
#+BEGIN_EXAMPLE
  Some example from a text file.
#+END_EXAMPLE
```

However, if a line needs to start with a `*`, `,*`, `#+` or `,#+` then you need to precede it with a comma:

```
#+BEGIN_EXAMPLE
  ,* Not an actual heading.
#+END_EXAMPLE
```

### Links

The rules for this are more complex so if the URL contains `[`, `]`, or `\` then it is easiest to use the `org-link-escape` function turns a link string into an escaped form.

## Lists

Lists are created within a heading's container.

`M-RET` adds new 'general' items and `M-S-RET` creates new checkbox items.

### Unordered Lists

Items are prefixed with `-`, `+`, or `*` (if not at the start of a line).

```
* Chores
  - Clean bathroom
  - Buy coffee
  - Buy eggs
    - A dozen free range
	- Medium
  - Order cat food
```

### Ordered Lists

Items are prefixed with numbers.

If you move items with `M-up`, `M-down`, `M-left`, and `M-right` then the numbers update automatically.

### Description Lists

A description list is ideal for creating a glossary, list of definitions, etc.

```
* Run Types
  - Recovery :: Short, easy-paced to loosen up
  - Easy :: Short to moderate at a comfortable pace
  - Long :: Steady, extended run to build stamina and confidence
```
 
### Checkbox Lists

Allow items to be checked off.

```
* Work Admin
  - [ ] Email John Smith
  - [x] Order printer ink
  - [ ] Book meeting room for Thursday
```

`C-c C-c` toggles the state of an item's checkbox.

If the list is nested then the parent item shows the state of the children if you use `C-c C-c`:

```
* Work Admin
  - [-] Book a meeting room for Thursday
    - [X] Check available times
	- [ ] Order tea and coffee
	- [ ] Tell attendees which room we are using
```

You can also add `[/]` or `[%]` to the parent (including the heading) to show the completion statistics and they work hierarchically. Again, you need to use `C-c C-c` to toggle the state of items.

```
* Work Admin [0%]
  - [-] Book a meeting room for Thursday [1/3] [33%]
    - [X] Check available times
	- [ ] Order tea and coffee
	- [ ] Tell attendees which room we are using
```
